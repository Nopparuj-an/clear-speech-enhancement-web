# UI mockups

Approved screen designs for v1 (see [../SPEC.md](../SPEC.md) §3). Each file is
one screen in the Design Component (`.dc.html`) format used by the design
canvas. Use them as the reference for layout, copy, sizes and colours. They
are not app code and do not run on their own: `support.js` is provided by the
canvas.

| File | Screen |
|---|---|
| `Import.dc.html` | Desktop · Import |
| `Processing.dc.html` | Desktop · Processing (with long-file warning) |
| `Main.dc.html` | Desktop · Editor + export panel (interactive) |
| `MobileImport.dc.html` | Mobile · Import |
| `MobileEditor.dc.html` | Mobile · Editor (interactive) |
| `MobileExport.dc.html` | Mobile · Export sheet (interactive) |

Waveforms in the mockups use generated placeholder data, and the numbers
(sizes, times, LUFS) are illustrative.
